# ThachOptimizer

## Công cụ tối ưu Windows PowerShell WinForms GUI

---

## Giới thiệu

**ThachOptimizer** là công cụ tối ưu hóa Windows được xây dựng bằng PowerShell với giao diện đồ họa WinForms. Công cụ cung cấp các chức năng tối ưu hệ thống, quản lý DNS/IP, cấu hình Firewall & Defender, và hỗ trợ cài đặt SQL Server 2005.

---

## Hướng dẫn sử dụng

### Yêu cầu hệ thống

| Yêu cầu | Chi tiết |
|---------|----------|
| Hệ điều hành | Windows (khuyến nghị Windows 10/11) |
| PowerShell | Windows PowerShell 5.1 |
| Quyền | Administrator (bắt buộc) |
| Mã hóa file | UTF-8 BOM |

### Cách chạy

1. Lưu file script với mã **UTF-8 BOM**, đổi đuôi thành `.ps1`
2. Mở PowerShell với quyền Administrator
3. Chạy lệnh sau:

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File "đường_dẫn\ThachOptimizer.ps1"
```

> **Lưu ý:** Script không thay đổi chính sách thực thi toàn cục, không tải mã từ mạng, không tạo tác vụ lịch trình.

## Tab 2: DNS và IP

### Chức năng chính

- **Chọn card mạng**: Hiển thị danh sách adapter vật lý đang hoạt động (IPv4)
- **Đặt DNS**: Chọn từ các preset phổ biến hoặc nhập DNS tùy chỉnh
- **Đặt IP tĩnh**: Cấu hình IP tĩnh với prefix và gateway
- **Chuyển về DHCP**: Khôi phục cấu hình IP tự động
- **Đọc cấu hình hiện tại**: Xem thông tin IP/DNS hiện tại của adapter

### DNS Presets có sẵn

| Preset | DNS 1 | DNS 2 |
|--------|-------|-------|
| Google | 8.8.8.8 | 8.8.4.4 |
| Cloudflare | 1.1.1.1 | 1.0.0.1 |
| Cloudflare Malware | 1.1.1.2 | 1.0.0.2 |
| Cloudflare Malware + Adult | 1.1.1.3 | 1.0.0.3 |
| Open DNS | 208.67.222.222 | 208.67.220.220 |
| Quad9 | 9.9.9.9 | 149.112.112.112 |
| AdGuard Ads/Trackers | 94.140.14.14 | 94.140.15.15 |
| AdGuard Full Protection | 94.140.14.15 | 94.140.15.16 |

### Quy tắc kiểm tra hợp lệ

| Trường | Quy tắc |
|--------|---------|
| IP tĩnh | Phải là IPv4 hợp lệ, mỗi octet ≤ 255 |
| Prefix | Từ 1 đến 32 |
| Gateway | IPv4 hợp lệ, không loopback (127.x), không multicast (224-239) |
| DNS | IPv4 hợp lệ |

> **An toàn:** Trước khi thay đổi IP, hệ thống tự động sao lưu registry của adapter. Nếu có lỗi, cấu hình cũ sẽ được phục hồi tự động.

## Tab 3: Firewall và Defender

### Quản lý Firewall

| Profile | Mô tả |
|---------|-------|
| Domain | Mạng domain doanh nghiệp |
| Private | Mạng riêng (nhà riêng, văn phòng) |
| Public | Mạng công cộng (quán cà phê, sân bay) |

Có thể bật/tắt từng profile riêng lẻ hoặc tất cả cùng lúc.

### Windows Defender

- Nút **"Mở trang Real-time protection"** mở trực tiếp trang cài đặt bảo vệ thời gian thực của Windows Defender
- Sử dụng giao thức `windowsdefender://` với cơ chế fallback tự động

---

## Tab 4: SQL 2005

### Quy trình cài đặt

1. Nhấn **"Chọn file cài đặt"** để chọn file `.exe` hoặc `.msi`
2. Hệ thống tự động **kiểm tra chữ ký số** (Authenticode Signature)
3. Nếu chữ ký không hợp lệ, hiển thị cảnh báo và yêu cầu xác nhận
4. Nhấn **"Cài đặt SQL Server 2005"** để bắt đầu

> ⚠️ **Lưu ý:** SQL 2005 chỉ hỗ trợ cài thủ công. Công cụ chỉ hỗ trợ chọn file, kiểm tra chữ ký số và xác nhận trước khi chạy.

## Cơ chế an toàn

### Sao lưu & Phục hồi

| Cơ chế | Mô tả |
|--------|-------|
| Backup Registry | Tự động sao lưu registry gốc trước khi thay đổi |
| Restore Point | Tạo điểm khôi phục hệ thống trước khi tối ưu |
| Phục hồi tự động | Tự phục hồi cấu hình IP cũ nếu có lỗi |
| Nút phục hồi | Phục hồi registry từ file backup gần nhất |

### Ghi log

- Log hoạt động và lỗi được ghi vào thư mục: `%USERPROFILE%\ThachOptimizer_Logs\`
- Tên file log: `Log_yyyyMMdd_HHmmss.txt`
- Log hiển thị trực tiếp trong textbox ở cuối giao diện, cập nhật mỗi 2 giây

|-----|-----------|

> - Luôn chạy với quyền Administrator
> - Đọc kỹ tooltip trước khi bật các tùy chọn nâng cao
> - Một số tùy chọn nâng cao chưa hỗ trợ sẽ bị vô hiệu hóa
> - Khởi động lại máy sau khi áp dụng tối ưu để thay đổi có hiệu lực
